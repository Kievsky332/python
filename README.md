## Описание проекта

Данный репозиторий содержит набор независимых Python-скриптов, каждый из которых решает определенную учебную или практическую задачу. Файлы пронумерованы для удобства навигации и отслеживания прогресса. Проект демонстрирует знакомство с базовыми конструкциями языка: переменными, циклами, условными операторами, функциями и работой с базовыми типами данных.

## Запуск скриптов

Для запуска любого из скриптов на вашем компьютере должен быть установлен интерпретатор Python.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Kievsky332/python.git
   ```
2. Перейдите в папку проекта
   ```bash
   cd python
   ```
3. Запустите нужный скрипт, указав его имя. Например:
   ```bash
   python Num1.py
   ```
